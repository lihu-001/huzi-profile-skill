# Style textures

Use only after the IP sentence exists. A texture is a material language plus one master method. Banner first, avatar derived.

There are 20 textures. Pick one. Do not run a twenty-skin circus on one account.

If the person does not publish in that practice, skip the pack.
Example — Lab kitchen only if they publish cooking. Indie pixel only if they ship games. Fashion plates only if they sell clothes.

Every pack below already assumes manufactured canvases (1-1 avatar, 3-1 banner) and the safe zones in safe-zones.md.

## Name patterns

Display name
- Firm / studio — HUZI, North Mill, Silt Lab
- Person-as-firm — Lin Shen, Zhou Nan
- Rare CJK only when the audience is Chinese and the user asked for it
- Role as name — Desk Proof, Count Room

Handle — 4-15, [A-Za-z0-9_], speakable. No xxx2024, official, real_.

## Pack recipes

### Studio plate (one-person company)

Use when the name is the firm. Default for HUZI-class accounts.
Do not use clothing labels, temple seals, or corporate gradient orbs.
Thesis: the door plate of a one-person studio.
Method: Vignelli name-as-system + Hara emptiness around the bio line.
Palette: #2A2723 #E8E0D4 #C4782B #1C1A17
Avatar: wood or painted-board nameplate, Latin wordmark only, optional tiny STUDIO line. Circle-safe.
Banner: same board. Do not repeat the name. Set the bio's offer in the live band — for HUZI that is workflows / teardowns / rerun, not a vague ai systems.
Names: HUZI / @huzi_lab ; North Mill / @northmill ; Silt Lab / @siltlab
Bio seed: One-person studio. [proof]. [what they refuse].

### Cold engineer

Use when the IP is specs, tools, failure reports, manufacturing, research ops.
Thesis: a spec sheet that learned to speak.
Method: Rams — one honest instrument, no styling.
Palette: #1B1E22 #C5CBD3 #5B8DEF #E8EAED
Avatar: one instrument on graphite — caliper, wafer shard, antenna. No face. No exploded collage.
Banner: one faint dimension line and one ghost part spanning the full field; keep the labeled focal detail clear of the avatar circle.
Names: Qinghui / @qinghui ; Tol Lab / @tol_lab ; Delta Spec / @deltaspec
Bio seed: I write things that reproduce. Failures get filed first.

### Night editor

Use when the IP is longform, editing, media criticism.
Thesis: a desk that stays on after midnight.
Method: Irma Boom — the page is the object.
Palette: #1A1410 #E7C9A0 #8B3A2A #F3EDE4
Avatar: one marked page corner or a lamp pool. Not a whole library set.
Banner: a single open signature over a full walnut field; let the desk surface continue behind the avatar circle without placing the signature there.
Names: Yenhang / @yenhang ; Desk Proof / @deskproof ; Lamp Desk / @lampdesk
Bio seed: I edit other people’s sentences and my own biases. Slow posts.

### Clear terminal

Use when the IP is platform notes, product walks, information design.
Never rain-glass, visors, wet neon, purple-cyan murk.
Thesis: the network as a readable map.
Method: Müller-Brockmann grid, one type size.
Palette: #F4F6F8 #1A1D21 #0B6E4F
Avatar: pale modular grid filling the circle. Wordmark plus the green caret as one unit. The grid is visible at 40px. Not cream-with-no-grid.
Banner: a spare schematic or overcast street fragment in the live band. High key.
Names: Xianhang / @xianhang ; Signpost / @signpost ; Deskmap / @deskmap
Bio seed: Notes from the seams of platforms. Write the path first.

### Field folio

Use when the IP is research notes, teaching, ethnography, clippings.
Old name Campus sticker — keep the paper, drop the cute collage.
Thesis: the folio is the product.
Method: Boom / Weingart — one annotated sheet, not a collage.
Palette: #F6F1E6 #2B2B2B #C45C26 #6B8F71
Avatar: kraft ground filling the circle, a cream pinned sheet as the face of the mark, stamp in the sheet. Must read as paper on board, not a flat logo.
Banner: one pinned sheet in the live band on kraft. No sticker explosion.
Names: Page Edge / @pageedge ; Folio / @folio_note ; Field Bin / @fieldbin
Bio seed: Lectures, fieldwork, scraps. Write first, decide later.

### Garden quiet

Use when the IP is slow essays, design restraint, attention.
Thesis: Song painting as a publishing cadence, not decoration.
Method: Hara emptiness — horizon, one small mark.
Palette: #E6E0D4 #3F4A3A #8FA08B #6E5A44
Avatar: one stone or one pine tip. Empty field is the mark.
Banner: mist horizon in the live band, 70 percent paper. No CJK unless requested.
Names: Zhezhi / @zhezhi ; On Stone / @onstone ; Yuwarm / @yuwarm
Bio seed: Slow posts. Clear takes. The garden matters more than the feed.

### Protocol kitchen

Use when they actually publish cooking or lab-like recipes.
Do not use for an AI account that does not cook.
Thesis: recipes and protocols are the same genre.
Method: Fukasawa — the tool disappears into use.
Palette: #F4F0EA #2C2C2C #C43B3B #D9C4A3
Avatar: one bowl, knife spine, or formula card.
Banner: three mise-en-place objects in the live band, not a restaurant brand.
Names: Shiwei / @shiwei ; Bench / @benchpot ; Ratio Lab / @ratio_lab
Bio seed: Cooking as protocol. Heat, failures, accidental deliciousness.

### Indie room

Use when they ship games or tools with a pixel constraint.
Do not costume a non-game IP as a mascot.
Thesis: limited palette as discipline.
Method: Saville — one unexpected surface for a release, only if they ship.
Palette: #1A1C2C #F4F4F4 #E83B3B #5D8AA8 #F2D35B
Avatar: 32-pixel mark that still reads at 40px. Not a cute animal unless that is the shipped character.
Banner: one side-scroll strip spanning the full width. Background tiles may pass behind the avatar; keep the character and critical pickups outside its circle.
Names: Bit Remain / @bitremain ; Onebit / @onebitwalk ; Attic exe / @atticexe
Bio seed: Tiny games and dev notes. Pixels are a constraint, not a filter.

### Macro board

Use when the IP is markets, structure, forecasts they will stand behind.
Thesis: one number, then the argument. No call-to-action fireworks.
Method: Aicher — one sign, one axis.
Palette: #0E1A2B #F4F7FA #D4A017 #4F7CAC
Avatar: one chalk glyph on navy.
Banner: one axis extending across the full field and one focal point outside the avatar circle.
Names: Board / @boardmacro ; Silt / @siltfx ; Count Room / @countroom
Bio seed: Macro, market structure, where my math was wrong. No calls.


### Edge type

Use when the IP is loud public writing, city-scale opinions, posters that must work at a glance.
Thesis: the letter is the architecture.
Method: Paula Scher — type hits the edge, the city is the grid.
Palette: #111111 #F4F1EA #E23D28
Avatar: HUZI so large the circular crop clips the letter edges on purpose. No inner badge.
Banner: one word of the offer line hitting the top of the type band while the typographic architecture and color fields continue across the full width.

### Programme

Use when the IP is systems, versions, numbered series.
Thesis: identity is a programme, not a picture.
Method: Karl Gerstner — modular units, the rule generates the layout.
Palette: #E8E4DC #1A1A1A #2F5D50
Avatar: a 3x3 unit grid with HUZI occupying four units. The unused units stay empty.
Banner: numbered modules in the live band, offer line in one module only.

### Concrete

Use when the IP is structure, logic, cold clarity without gadgets.
Thesis: one geometric relation is the whole mark.
Method: Max Bill — concrete art, proportion as content.
Palette: #F2F2F0 #1C1C1C #C43C2B
Avatar: HUZI locked into one square and one circle relationship. No decoration.
Banner: one hard rectangle in the live band holding the offer line.

### Specimen

Use when the IP is writing, typography, editing, publishing craft.
Thesis: the account is a type specimen for one voice.
Method: historical specimen sheet — one cut, one size shown honestly.
Palette: #F7F3EA #1A1A1A #8A1D1D
Avatar: HUZI as a specimen word, hairline registration marks at corners inside the circle.
Banner: the offer line set as a second specimen size, not a slogan.

### Stencil crate

Use when the IP is shipping work, drops, builds that leave the studio.
Thesis: the crate is the announcement.
Method: industrial stencil / Fluxus mail — one stencil, no illustration.
Palette: #C4A36A #1B1B1B #F2EBD8
Avatar: stenciled HUZI on plywood grain, broken stencil bridges visible.
Banner: the same stencil for the offer line on crate wood in the live band.

### Docket

Use when the IP is argument, critique, records, accountability.
Thesis: a filing, not a mood.
Method: severe document — Tschichold new typography, flush, no ornament.
Palette: #F5F2EA #121212 #6E1F1F
Avatar: HUZI as a case caption, thin rules above and below.
Banner: docket header + the offer line as the matter title. Left empty.

### Weather plate

Use when the IP is conditions, field notes, "what changed today".
Thesis: a daily plate, not a forecast brand.
Method: Swiss information design — one diagram, one reading.
Palette: #D9E2E8 #1E2A32 #C45C1A
Avatar: HUZI plus one small isobar or wind barb as the only sign.
Banner: a spare weather plate in the live band with the offer line as the legend.

### Color field

Use when the IP needs graphic force without cute or neon.
Thesis: one plane, one sign.
Method: Ikko Tanaka — color field + one mark. Latin only unless CJK requested.
Palette: #E31C23 #F6E7C1 #1A1A1A
Avatar: HUZI in black or cream on a single red (or gold) field filling the circle.
Banner: the color field spans the full canvas; place the mark and banner line outside the avatar circle.

### Film gate

Use when the IP is sequences, teardowns of moving work, frame-by-frame thinking.
Thesis: one frame is enough.
Method: structural film — gate, not cinema poster.
Palette: #111111 #EDE6D6 #C2A15B
Avatar: HUZI inside a film-gate rectangle, sprocket holes only on top and bottom edges.
Banner: one wide frame in the live band, offer line as a slate.

### Job ticket

Use when the IP is studio process, commissions, "what is on the bench".
Thesis: work is ticketed.
Method: carbon job ticket / letterpress docket — numbered form.
Palette: #EFE7D6 #1A1A1A #2B5F8A #C45C26
Avatar: HUZI as the shop name on a job ticket that fills the circle. One stub tear.
Banner: ticket fields in the live band; offer line in the job description row.

### Letterpress chase

Use when the IP is craft publishing, physical making, ink.
Thesis: type is metal, locked.
Method: letterpress chase — furniture, quoins, one locked line.
Palette: #2A2420 #D7C7A8 #8C2F21
Avatar: HUZI as locked metal type, shoulder and nick visible, dark bed.
Banner: a locked line of the offer in the live band, furniture around it.
