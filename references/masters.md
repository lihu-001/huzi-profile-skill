# Master methods

Reference how they decide, not their trademarks. Do not recreate MUJI, Braun, Olympics, D&AD Pencil, Factory Records, or any other owned mark.

D&AD 2025 juries said too many identities look alike. The work that wins breaks an expected code and still fits the purpose. That is the bar.

## Methods to steal

- Kenya Hara — emptiness as a receptacle, not Western minimalism. Horizon, paper, one small mark. Use for Garden quiet and for any studio that publishes restraint.
- Dieter Rams / Braun — one object, honest material, no styling. Use for Cold engineer.
- Josef Müller-Brockmann — grid, one size of type, asymmetric flush. Use for Clear terminal and Macro board.
- Massimo Vignelli — the name is the system. Few typefaces, brutal clarity. Use for Studio plate.
- Irma Boom — the object is the content. Paper, edge, thickness. Use for Night editor and Field folio.
- Otl Aicher — pictogram as thought. One sign, no decoration. Use for Macro board.
- Ikko Tanaka — color field + one sign, Japanese graphic force without cute. Use when CJK is allowed.
- Peter Saville — a single unexpected surface for a cultural product. Use for Indie room only if they actually release work.
- Naoto Fukasawa — without thought, the tool disappears into use. Use for Protocol kitchen.
- Paula Scher — type as architecture, letters hit the crop. Use for Edge type.
- Karl Gerstner — programme generates layout. Use for Programme.
- Max Bill — proportion is the content. Use for Concrete.
- Jan Tschichold — new typography, flush document. Use for Docket.
- Ikko Tanaka — color field + one sign. Use for Color field (Latin unless CJK asked).

## How to write the prompt

Name the method in one clause, then describe only our object and our bio line.
Good — walnut letterhead, Vignelli-clear grotesque, the line workflows teardowns rerun in the live band, emptiness around it in the Hara sense.
Bad — in the style of MUJI poster, Braun logo, Saville Unknown Pleasures.

## Stunning vs tidy

Tidy — centered word, tasteful wood, correct margins.
Stunning — one decision you can describe later (the type is cut from the bio and is the only image; the banner is a horizon with the offer sitting on it; the mark is a caliper that is also the H).
If you cannot name that decision in one sentence, the pack is not ready.
